# Topos

## 場・配置・関係

Topos は、Type が存在し、接続し、使われ、対話が行われる「場」を扱う。

Ontology が **何があるか** を、Topology が **どうつながっているか** を扱うなら、Topos はそれらが実際に展開される **場・文脈・学習環境** を指す。

```text
TYPE
 │
 ├─ Ontology    何があるか
 ├─ Topology    どうつながっているか
 └─ Topos       どこで・どの文脈で展開するか
      │
      ├─ Agora
      ├─ Schola
      ├─ Dialogue
      └─ Practice
```

## Agora Schola

Agora Schola は Topos の一つであり、問い・対話・研究・実践を循環させる学びの場である。
