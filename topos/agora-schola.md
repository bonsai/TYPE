# Agora Schola

## アゴラ・スコラ

**Agora Schola** は、問いを持ち寄り、対話によって概念を磨き、世界への理解と行為を更新するための学びの場である。

Agora（公共の対話空間）と Schola（学び・思索の場）を接続し、教える側と学ぶ側を固定せず、**問い・対話・研究・実践**を循環させる。

## 目的

- 問いを持ち寄る
- 概念を定義する
- 異なる思想・視点を対話させる
- Type / Ontology / Topology を検討する
- Language Game として概念の「使われ方」を観察する
- Agentとして世界に働きかける
- 実践結果を再び問いへ戻す

## TYPEとの関係

Agora Schola は `TYPE` の概念を、単に定義するだけでなく、**対話によって使い、検証する場**として位置づける。

```text
TYPE
 │
 ├─ Ontology       何があるか
 ├─ Topology       どうつながるか
 ├─ Language Game  どう使われるか
 │
 ↓
Agora Schola
 │
 ├─ Question
 ├─ Dialogue
 ├─ Research
 ├─ Practice
 └─ Reflection
 │
 ↓
World
```

## 対話者

### Plato

Form / Idea、対話、哲学的探究。

### Hiroki Azuma

データベース、一般意志、現代社会における知とコミュニケーション。

### Ludwig Wittgenstein

Language Game、意味と使用、言語による世界の捉え方。

三者の対話は、単一の正解を決めるためではなく、概念の境界と使用可能性を明らかにするために行う。

## Agentとの接続

Agora Schola の参加者は、単なる閲覧者ではなく、環境を観察し、問いを立て、対話し、行為する Agent となる。

```text
Environment
    ↓
Observation
    ↓
Question
    ↓
Dialogue
    ↓
Cognition
    ↓
Decision
    ↓
Action
    ↓
Environment Change
    ↺
```

したがって、学習は知識の取得だけではなく、**世界との相互作用による状態変化**である。

## 学びのプロトコル

1. **Observe** — 世界を見る
2. **Question** — 問いを立てる
3. **Dialogue** — 他者と対話する
4. **Define** — 概念を定義する
5. **Research** — 根拠を調べる
6. **Experiment** — 試す
7. **Act** — 世界に働きかける
8. **Reflect** — 結果を振り返る
9. **Update** — 概念・Type・World Modelを更新する

## 最小単位
